«Антискам» — телефонный голосовой AI-агент

Принимает звонок вместо человека и удерживает мошенника на линии: время оператора колл-центра уходит впустую, а не на жертву. Разговор записывается и расшифровывается.

  • Полный тракт звонка: SIP-транк → STT → LLM → TTS, с настройкой определения конца фразы (EOU)
  • Проработка речевого поведения персонажа: интонации, паузы, оговорки — чтобы диалог не выдавал бота
  • Перебивание (barge-in), двухдорожечная запись, живая лента разговора и суфлёр-пульт в Telegram
  • Эксплуатация: VPS, systemd-юниты, ротация записей, сторожевые механизмы, предохранитель аудиоочереди
  • 380+ автотестов; каждая фаза — через независимое ревью кода

VoiceAgent — персональный AI-ассистент

Telegram-ассистент, который не просто отвечает текстом, а действует: вызывает инструменты, планирует задачи, работает с календарём.

  • Интеграция LLM API и tool calling: модель сама выбирает и вызывает функции
  • Планирование и фоновое выполнение задач по расписанию
  • Конфигурации вынесены из кода, токены и ключи — в защищённом хранении
  • Приватный репозиторий на GitHub — доступ по запросу

Путь одного звонка

Пять звеньев, каждое со своим бюджетом задержки: пауза дольше секунды — и собеседник понимает, что говорит с машиной.

02 · слухSTT в реальном времени, определение конца фразы
03 · мысльLLM-диалог: персона, логика, вызов инструментов
04 · голосTTS-синтез, барьер перебивания, аудиоочередь
05 · работаVPS, systemd, запись, логи, сторожа, тесты
